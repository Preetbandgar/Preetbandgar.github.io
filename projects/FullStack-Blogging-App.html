Java Blogging Application: Build and Deployment Setup

Repository: FullStack-Blogging-App

PROJECT

Overview

I worked with a Java blogging application to practise build automation and deployment packaging. The repository has a Jenkinsfile, Docker resources and Kubernetes configuration. They are separate pieces: Jenkins only runs the Maven stages.

Implementation

  • Configured Jenkins to run Maven compile, test and package using Java 17.
  • Kept Docker and Kubernetes files alongside the application for container packaging and deployment configuration.

What runs in Jenkins

The committed Jenkinsfile uses Java 17 and Maven to compile, test and package the application. Docker packaging and Kubernetes deployment configuration are maintained separately from this Maven CI pipeline.
