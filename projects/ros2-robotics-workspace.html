Repository: ros2-robotics-workspace

PROJECT

Overview

This is my ROS 2 Jazzy practice workspace for writing and testing Python nodes. I use separate packages to explore robot state, sensing, safety logic and navigation-related interfaces.

A Docker environment and GitHub Actions workflow make the development setup easier to reproduce.

Implementation

  • Wrote rclpy publishers, subscribers, service clients/servers and action examples using custom ROS 2 interfaces.
  • Organised nodes, parameters, launch files, sensor examples and test cases across packages.
  • Added pytest and launch_testing examples for selected behaviour.
  • Configured GitHub Actions to build a Jazzy Docker image, check ROS 2/Python/colcon availability and publish the image on main-branch changes. These checks are not a complete test suite for every ROS 2 node.

What I checked

I use this workspace to test how individual ROS 2 pieces fit together: nodes, interfaces, launch files and test cases. The Docker workflow builds the Jazzy development image and checks that ROS 2, Python and colcon are available before publishing. The CI check verifies the containerized development environment; ROS 2 test examples are maintained in the workspace.
