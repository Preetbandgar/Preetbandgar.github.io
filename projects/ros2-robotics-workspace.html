Modular ROS 2 Robotics Software Development

Repository: ros2-robotics-workspace

PROJECT

Overview

I use this ROS 2 Jazzy workspace to practise writing and integrating Python nodes in smaller, testable packages. It includes custom interfaces, robot-state and sensor examples, safety logic, and launch-based tests. I also maintain a Docker environment to keep development and CI setup consistent.

Implementation

  • Wrote rclpy publishers, subscribers, services, actions and callbacks across several example packages.
  • Defined custom message, service and action interfaces for communication between nodes.
  • Added testing examples with pytest and launch_testing, along with simulated sensor and rosbag2 material.
  • Set up a ROS 2 Jazzy development Dockerfile and GitHub Actions workflow. CI builds the image, runs basic environment checks and publishes the image to Docker Hub on main-branch changes.

What I checked

I use this workspace to test how individual ROS 2 pieces fit together: nodes, interfaces, launch files and test cases. The Docker workflow builds the Jazzy development image and checks that ROS 2, Python and colcon are available before publishing. The CI check verifies the containerized development environment; ROS 2 test examples are maintained in the workspace.
