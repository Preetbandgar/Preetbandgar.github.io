YelpCamp: Docker and Compose Setup

Repository: Yelp-Camp-Web-App

PROJECT

Overview

I worked on containerising YelpCamp, a course-based Node.js/Express campground application. My focus was Docker, Compose and the settings needed to run the app locally.

Implementation

  • Configured the Docker image and Compose environment for local execution.
  • Documented the application settings for MongoDB Atlas, Cloudinary and Mapbox.
  • Credited Colt Steele’s course and the upstream application rather than presenting the full web application as original work.

Running the application

I worked on the Docker and Compose configuration for this Node.js/Express app, including its runtime settings for the database and external services. The application is based on Colt Steele’s course; this project documents my container and deployment setup around it.
