AWS EKS Infrastructure with Terraform

Repository: Terraform-aws-eks

PROJECT

Overview

I organised Terraform configuration for the AWS infrastructure used by the OpenTelemetry Demo. The repository separates the VPC, EKS and remote-state setup so each part is easier to understand and maintain.

Implementation

  • Separated network and Kubernetes-cluster configuration into VPC and EKS modules.
  • Documented an S3 backend and DynamoDB state-locking setup.
  • Included commands for initialisation, validation, planning, applying and removing the demonstration infrastructure.

How I organized it

I separated the VPC and EKS modules and set up S3 and DynamoDB for Terraform state management. The README records the order for creating the backend, initializing the main configuration, validating and applying it. I kept cleanup commands beside the deployment steps so the demo infrastructure can be taken down after use.
